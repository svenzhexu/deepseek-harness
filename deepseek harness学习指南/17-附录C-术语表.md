# 附录 C · 术语表

> DSH 用一套精确的词汇。混用这些词，会导致你把 A 机制的问题当成 B 机制来修。

---

## 核心名词

**harness**
模型外面那层运行时。六项职责：循环、行动、上下文、记录、边界、接口。

**agent**
一个 harness 实例 + 一份组合 + 一个会话。在 DSH 里 agent 是"组装出来的"，不是"代码写死的"。

**turn**
一次输入的完整消化。开启于第一条输入被认领，结束于"不再欠任何事"。**可以包含零个 step。**

**step**
一次模型请求 + 它引发的工具执行。一个 turn 里 0..N 个。

**round**
外层的策略迭代，比如 goal 轮、Ralph 轮。**不等于 turn**——一轮可能包含多个 turn，人类的普通 turn 也不消耗 goal 轮次。

**session（会话）**
一条 append-only 的 `SessionEvent` 日志，加上由它派生的状态。它是持久事实的单位。

**surface（表面）**
日志里"产消息"的那部分子集。只有 `system/message`、`developer/message`、`user/message`、`assistant/message`、`tool/result` 五种事件在 surface 上。模型历史由 surface 派生。

**projection（投影）**
把提交的事件增量折叠成一份 typed state 的机制。消费方用 `stateOf()` 读。

**compaction（压缩）**
用摘要 + `surfaceOp: replace` 把一段历史从 surface 上**遮蔽**掉。原始事件不删除。

## 组合相关

**profile**
一个具名组合，存在 Harness home 里。列出它叠的 bundle、装的外部插件、以及用户 patch。内置模板：`web` / `headless` / `sdk` / `sdk-minimal` / `acp`。

**bundle**
可分发的插件行集合。`package.json` 的 `dsh.bundle` 指向它的 patch 文件。

**patch**
按 row id 覆盖或插入入口。**整行替换 config，不是深合并。**

**preset**
只在某个 agent 内部生效的子组合，通过 `config.plugins` 声明。定义急切加载，但只影响之后创建的 agent。

---

## 扩展相关

**plugin（插件）**
一个导出 `apply(ctx)` 的 TypeScript 模块。框架调用它，它往 `ctx` 上注册能力。

**fiber**
每个插件实例的作用域与生命周期状态机：PENDING → LOADING → ACTIVE → UNLOADING → DISPOSED，失败进 FAILED。

**effect**
通过 `ctx.effect()` 注册的可逆副作用。插件卸载时执行 disposer；多个异步 disposer 并发，无串行保证。

**service（服务）**
挂在 `ctx.<key>` 上的能力。通过声明合并补类型。缺失时依赖它的插件停在 PENDING。

**seam（能力边）**
一个可替换能力的**完整三角色**：Service Definition（定义接口与 `ctx.key`）、Service Provider（实现）、Consumer（使用）。**一个角色不构成 seam。**

**scope（作用域）**
每个 agent 的注册单元。通过 `agent.ctx` 注册 → 只对这个 agent 可见且随它销毁。事件过滤靠 dispatch 时的 carrier，不靠注册位置。

**waterfall**
监听器串联、必须显式调用 `next()` 才把控制权交给下一个的事件。**忘了 `next()` 会静默短路整条链。**

**broadcast**
所有监听器都跑、无法被阻止的事件。

## 事件与数据

**session event**
持久事实，落进日志，可重放。例如 `turn/start`、`tool/result`。

**agent event**
实时控制，不落日志。例如 `agent/status`、`agent/assistant-stream`。

**model-visible ⟺ logged**
铁律：任何进入模型请求的内容，都必须能从会话日志重建。违反它会导致 fork / resume / 回放不一致。

**StreamChunk**
适配器吐出的带类型增量。主要变体：`block-start` / `text-delta` / `reasoning-delta` / `tool-call-delta` / `block-end` / `usage` / `finish`。

**ContentBlock**
模型消息的最小单位。通过 `ContentBlockMap` 声明合并可扩展。

**FinishReason**
终止原因：`stop` / `tool-calls` / `max-tokens` / `aborted` / `error`。

---

## 工具

**ToolDefinition**
工具的五部分：name/description、parameters、execute、isConcurrencySafe、presentation。

**executionMode**
`parallel` 或 `exclusive`。没声明 `isConcurrencySafe` → 独占（保守默认）。

**PTC**
Programmatic Tool Calling：模型写代码调用宿主提供的异步函数。

---

## 编排

**subagent**
委派给另一个 agent。本地 provider（spawn / fork）保留可续会话；外部 provider（ACP / SDK / Codex / Claude Code）执行一次。

**workflow**
用 JavaScript 脚本做扇出编排。脚本里没有文件系统、网络、定时器。

**goal**
附加在已有会话上的持久目标。四阶段：`active` / `paused` / `blocked` / `complete`。激活状态**不持久化**，resume 后必须人工重新授权。

**schedule**
定时跟进。Host 拥有的提醒记录。

---

## 容易混淆的三组

| 易混 | 区别 |
|---|---|
| turn vs step | turn 是"一次消化"，step 是"一次模型请求"。turn 可以有 0 个 step |
| 日志 vs 历史 | 日志是全集，历史是 surface 视图（压缩会遮蔽） |
| 删除 vs 遮蔽 | 删除不可逆；遮蔽只是从 surface 移除，日志还在 |
| 注册看 ctx vs 分发看 carrier | 前者决定"谁看得见"，后者决定"谁能收到事件" |
| spawn vs fork | spawn 全新会话；fork 继承父级已完成的 turn |
