## 二、五个必读包

### 1. `packages/core/agent-loop` —— 循环

```
src/agent.ts         ReactLoopAgent：turn/step 状态机（读 turn() 与 step()）
src/inbox.ts         收件箱：durable 投影 + 循环私有 claim 状态
src/tool-calls.ts    工具调度：独占屏障 + 有界并行池
src/index.ts         AgentLoop 服务、配置、注册
src/runtime-context.ts  每 step 的运行时上下文
```

### 2. `packages/core/session` —— 日志

```
src/types.ts         SessionEventMap（事件目录）、SurfaceEventType、SurfaceOp
src/index.ts         Session 类：append / deriveMessages / fork
src/surface.ts       foldSurface：把事件折成有序表面
src/repair.ts        崩溃修复
src/preparation.ts   会话准备（fork/seed）
```

### 3. `packages/llm/llm` —— 模型

```
src/types.ts         ContentBlockMap、StreamChunk、FinishReasonMap、TokenUsage
src/assembler.ts     BlockAssembler：delta → 块
src/message.ts       消息构造辅助
src/retry-policy.ts  重试策略
```

### 4. `packages/core/tools` —— 工具

```
src/index.ts         ToolDefinition、执行管线、四个 waterfall
src/schema.ts        defineTool、参数校验、ToolArgsError
src/presentation.ts  呈现类型
src/ptc.ts           程序化工具调用（PTC）
```

### 5. `packages/core/agent` —— 契约

```
src/index.ts         AgentService：create / resume / register / get
src/runtime-types.ts 全部 agent/* 事件声明
src/model-selection.ts  模型选择相关的默认监听器
```

## 五、读代码的三条捷径

1. **从事件名反查**：`grep "'tool/result'"`，一次找到生产者、消费者、测试。比顺 import 链走全。
2. **先读包 README 的 `Understand the implementation`**：它比源码注释浓缩，比外部文档准确。
3. **看测试**：`packages/*/*/tests/` 是行为说明书，比文档精确。
