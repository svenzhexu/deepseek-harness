# 全书大纲

## 一、这本书要解决的问题

一个 LLM 只会"文本进、文本出"。要让它在真实环境里持续做事，外面必须套一层运行时——这一层叫 **harness**。

DeepSeek Harness 的特殊之处在于：**它把这层运行时的每一个部件都做成了可替换的插件**，包括 agent 循环本身。这带来两个后果：

- 好处：任何能力都能换、能加、能隔离。
- 代价：没有 `main()` 可以从头读到尾，你必须先有一张地图。

这本书就是那张地图。它按"先看全貌 → 再拆内核 → 再看能力面 → 最后自己组装"的顺序展开。

## 二、三条主线

全书始终并行推进三条线，每一章都会在三线上各走一步：

| 主线 | 问题 | 对应章节 |
|---|---|---|
| **概念线** | agent / harness / memory 到底是什么 | 第 1、5、6、9 章 |
| **实现线** | DeepSeek 用什么机制实现它们 | 第 2–9 章 |
| **构建线** | 我怎么在它上面长出业务 | 第 10–14 章 |

## 五、每一章的结构

所有日课章节统一采用七段式，方便你按同一节奏推进：

1. **本日目标** —— 一句话说明今天结束时你应该会什么。
2. **核心概念** —— 3–6 个概念，每个都用"它解决什么问题"切入，不堆定义。
3. **代码坐标** —— 表格：`文件:行号` + 这一行为什么值得看。
4. **精读片段** —— 1–2 段真实代码 + 解读，训练"读源码"而不是"读文档"。
5. **动手** —— 可执行动作，必须真的跑。
6. **验收** —— 3–5 个问题，答不上来说明没学会，回头重读。
7. **常见误解 + 延伸阅读**。

## 六、读完的验收标准

不要用"读完了"当标准。用这五条：

- [ ] 能在白纸上画出一次 turn 的完整事件序列，并标出哪些是 durable、哪些是 live。
- [ ] 能解释"模型可见 ⟺ 已记录"，并说出违反它会怎样炸。
- [ ] 能说清 capability seam 的三角色，并举出三个例子。
- [ ] 能在不改 agent-loop 的前提下，用插件改变 agent 的行为。
- [ ] 能独立做出第 14 章的 capstone，并通过它的验收清单。

五条全过，才算"精通"。前四条是理解，第五条是能力。
