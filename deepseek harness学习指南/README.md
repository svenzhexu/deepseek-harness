# DeepSeek Harness 学习指南

> 一本从源码出发、按两周编排的 DSH 教程。
> 读完的标准不是"知道它有什么"，而是**能讲清它为什么这样设计，并且能自己组装出一个可用的业务 agent**。

---

## 这本书是什么

这不是官方文档的复述。官方文档回答"这个 API 是什么"，这本书回答三个文档不回答的问题：

1. **一个 LLM 是怎么被变成 agent 的？** 中间那层叫 harness，它到底做了哪六件事。
2. **DeepSeek 为什么这样实现？** 每个设计决定放弃了什么、换来了什么。
3. **我怎么在它上面长出业务？** 从配置到工具到记忆到嵌入，一条可执行的路径。

全书 **14 章 = 14 天**，每章对应源码里的真实文件与行号。读完一章，你应该能合上书，在白纸上把它讲出来。

---

## 怎么读

| 你有多少时间 | 读哪些 |
|---|---|
| 只有 5 天 | 第 1、2、5、6、11、14 章 |
| 完整两周 | 全部，按顺序 |
| 只想搞定业务 agent | 第 10–14 章，但第 5、6 章必须先读 |

**每天的节奏**（约 2–3 小时）：

```
40%  精读本章的「代码坐标」——打开 VSCode，真的跳到那些行
30%  做「动手」部分——不跑起来等于没学
20%  回答「验收」——答不上来就回头重读
10%  写 5 行笔记——今天搞懂了什么、哪里还模糊
```

**一条纪律**：第 1–9 章不要写业务代码，第 10–14 章不要深挖内核。混着来两头都做不深。

## 前置条件

- 已 clone 仓库，`pnpm install` 成功，`pnpm run typecheck` 通过。
- Node 22.19+ / 24+，pnpm 11.28.5（corepack）。
- 装了桌面客户端也行，但**验证源码改动一律用 `pnpm dsh web`**——客户端跑的是 `app.asar` 里的打包副本，改源码对它零影响。

## 一个约定

书里所有路径都相对于仓库根目录。代码坐标写成 `文件:行号`，例如 `packages/core/agent-loop/src/agent.ts:298`，你可以直接 `Ctrl+P` 粘贴跳转。

版本提醒：项目处于 developer preview，行号会漂移。**跳不到时用符号名搜索**（`Ctrl+T` 搜 `ReactLoopAgent`、`deriveMessages`），不要死记行号。
